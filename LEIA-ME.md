# Pós-Venda S&P · versão para telemóvel

Aplicação web para assistências técnicas e comissionamentos. Não depende do Claude nem de contas.

- Cada técnico abre o endereço e instala no ecrã principal.
- Os serviços ficam guardados no telemóvel de cada técnico, também sem rede.
- No fim do serviço, o relatório PDF partilha-se pelo menu do telemóvel (email, WhatsApp, OneDrive).
- "Exportar serviço" gera um ficheiro com o serviço completo, para o escritório ou para outro telemóvel ("Importar ficheiro de serviço").
- O catálogo de equipamentos e peças prepara-se num telemóvel e passa aos outros com "Exportar catálogo" / "Importar catálogo".

## Instalar
- Android (Chrome): abrir o endereço › menu ⋮ › Instalar aplicação.
- iPhone (Safari): abrir o endereço › Partilhar › Adicionar ao ecrã principal.

No iPhone, instalar no ecrã principal é obrigatório: o Safari apaga os dados de sites que não são abertos há 7 dias, e as aplicações do ecrã principal estão isentas.
